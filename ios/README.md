# WJXTester for iOS

这是问卷星测试脚本的原生 iOS 版本，支持：

- 在应用内替换 HTTPS 问卷地址，单条和批量页面共享最近一次地址；
- 手动填写或生成 6 位测试工号和测试姓名；
- 经授权确认后单次提交；
- 使用可增加、删除的名单卡片填写姓名、工号和邮箱，卡片数量就是提交数量；
- 名单卡片集中在导航栏菜单的“名单管理”页面，主提交页显示数量和完整状态；
- 名单内容、顺序及增删结果会自动持久化，应用重启后继续恢复；
- 每张卡片实时显示缺失字段、邮箱格式、重复工号和重复邮箱状态；
- 邮箱为可选字段；留空或问卷不存在邮箱题时自动跳过，填写时校验格式和重复；
- 姓名、工号、邮箱可分别设置问卷题号，默认分别为 2、1、3；
- 可从问卷页面标题自动识别姓名、工号、邮箱的实际题号，识别不全时支持手动修正；
- 使用独立的隐藏 WebKit 会话提交，每次最多 10 份名单；全部页面准备完成后统一放行提交；
- 不设置额外等待时间；立即模式在页面全部准备好后统一提交；
- 定时模式会提前预加载并填写全部页面，到设定分钟统一放行提交，并支持取消与倒计时；
- 定时任务采用双重时间校验，并在 WebKit 内锁定提交请求，到点前不会发送问卷 POST；
- 批量页实时显示带时间戳的运行日志，包括每条记录的开始、成功、验证、失败和取消状态；
- 显示答卷号和结果页；
- 出现安全验证时切换到内嵌网页，由用户手动完成验证；
- 通过 GitHub Actions 构建无证书 IPA。

## GitHub 构建

1. 把仓库推送到 GitHub。
2. 打开仓库的 **Actions** 页面。
3. 选择 **Build unsigned IPA**，点击 **Run workflow**。
4. 构建完成后，从任务底部的 **Artifacts** 下载 `WJXTester-unsigned-ipa`。

下载得到的是无证书 IPA，不能直接安装到普通 iPhone。需要使用 AltStore、SideStore、
Sideloadly 或开发者证书签名后安装。

## 本机 Xcode 构建

需要 macOS、Xcode 以及 XcodeGen：

```bash
brew install xcodegen
cd ios
xcodegen generate
open WJXTester.xcodeproj
```

批量任务确认后会立即申请 iOS 有限后台执行时间，切换到其他应用后可短时间继续预加载和提交，
后台授权与到期状态会写入运行日志。iOS 通常只授予几十秒，长时间定时仍可能被系统挂起；
要在锁屏、强制退出或长时间后台后保证整点执行，必须改用服务器端调度；
隐藏浏览器使用 iOS 系统 WebKit，并非 Chromium/Playwright；遇到验证码会停止对应记录并写入日志。
应用仅用于本人管理或已获授权的问卷测试，不包含验证码绕过功能。
